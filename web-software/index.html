Web & Software

Tools and websites I've designed, built, and deployed.

ENGINEERING TOOLS

Pod Control App — A web-based control console for my Pod Bot robots. Users can add any number of robots and control them all from a single screen, the same one-operator, many-vehicles model used in fleet autonomy. I built it from scratch using AI coding agents in VS Code and deployed it on Netlify. Demo access available on request.

Euler Angles Visualization — An interactive visualization of yaw, pitch, and roll (Euler angle) rotations. I built it on my own initiative during an aerospace course to help classmates build intuition for 3D rotations. It wasn't assigned, and it was well received in class.

IN PROGRESS

The CRASH Lab — A new website for the CRASH Lab at the University at Buffalo, where I lead the HERMES mechanical team, showcasing the lab's research. Currently in development.

CLIENT WEBSITES

Devora Car Service — A complete website for a family-owned private transportation business in Boca Raton, Florida, covering services, fleet, airport transfers, and one-tap call, text, and WhatsApp booking.

Express Passport USA — A multi-page website for a family-owned, licensed passport expediting service, with service tiers, a step-by-step process flow, and contact and booking pages.

My Next Step Forward — A website I built for a life-coaching client that runs a live workshop series end to end: workshop registration, Stripe checkout for both the full series and recordings-only access, Zoom-hosted live sessions, and a members page where enrolled participants access session recordings.
